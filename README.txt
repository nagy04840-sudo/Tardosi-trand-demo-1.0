PUBLIKÁLÁS GITHUB PAGES-RE:
1. Hozz létre egy új, üres repository-t: https://github.com/new
   Javasolt név: tardosi-trans-demo
2. Töltsd fel az index.html fájlt a repository gyökerébe (Add file -> Upload files -> Commit changes).
3. Nyisd meg a repository Settings menüpontját -> Pages.
4. Source: Deploy from a branch -> Branch: main -> Folder: /(root) -> Save.
5. Várj 1-2 percet, majd nyisd meg: https://nagy04840-sudo.github.io/tardosi-trans-demo/
